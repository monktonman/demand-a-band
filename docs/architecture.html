Core User Flow — Fan Journey
1

Sign Up

Register with email/password. JWT session created.

→
2

Onboarding

Select favorite bands (from 1,000), mark dream shows, set city + radius.

→
3

Browse

Explore artists catalog, view proposed events, see pledge progress.

→
4

Pledge

Select quantity, save payment method (Stripe SetupIntent). No charge yet!

→
5

Threshold Met

Enough fans pledge → status changes. Notified via in-app + email.

→
6

Event Confirmed

Admin confirms → cards charged via Stripe PaymentIntents. Tickets secured!

👑
Admin Flow — Event Lifecycle
1

Analyze Demand

Dashboard shows demand signals, band preference trends, geographic heat.

→
2

Create Event

Select band + venue + date. Set ticket price, min pledges, deadline.

→
3

Monitor Pledges

Watch pledge progress toward threshold. Send notifications at milestones.

→
4

Confirm / Cancel

Confirm → charge all cards. Cancel → release all pledges. Both notify fans.

Event N → 1 Venue Each event at one venue

Unit Economics

Service Fee Model

Under $15 ticket $3.50 flat
$15+ ticket 12% of face value
$35 ticket example $4.20 fee
$65 ticket example $7.80 fee

Example Event: $35 ticket × 150 fans

Ticket revenue $5,250
Service fees (12%) $630
Stripe processing (~2.9%+30¢) −$216
DAB net per event ~$414

Future: Radio Station Model

Station gets 8-9% service fee
DAB platform fee 3-4% service fee
Station brings Audience + relationships
DAB provides Tech platform + payments
